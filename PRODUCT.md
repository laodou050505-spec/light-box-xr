# 光匣 / LUMEN BOX

<!-- impeccable:product-schema 1 -->

## Platform

android

## Product Purpose

A tabletop spatial puzzle: build a supported structure with a limited number of cubes so its front and side projections both match their targets. Twelve levels progress in order.

## Operating Context

The isolated title scene offers START and EXIT. START unloads the title and opens the existing world-space puzzle and tutorial. Mouse and tracked PICO controller rays are supported. Physical headset comfort remains unverified.

## Capabilities and Constraints

Preserve the gameplay, model transforms, lights, level data and authored spatial layout. Title images must retain their aspect ratio, readable direction and working world-space hit targets. Desktop verification cannot establish physical-controller comfort.

## Brand Commitments

Chinese name 光匣; English name LUMEN BOX. User requests Tripo Nano Banana artwork, designed English lettering (including generated lettering), and visible button feedback. Desktop reference images are layout inspiration only. On 2026-09-08 the user explicitly delegated concept and production decisions to the agent.

## Evidence on Hand

Existing title scene, gameplay scene, 12-level validation, PICO emulator evidence in VisualQA. Source of prior work: Codex task 光匣：结构搭建.
